PersonalPaper v2.1 · system architecture · 2026-10-17

Agent, hosted environment, repository

Locked 2026-10-17; vocabulary updated 2026-10-25 (v2.1.1: what this page called a profile is now a topic, see docs/prds/v2.1.1-topic.md; v2.1.2: a category is now a subtopic, see docs/prds/v2.1.2-subtopic.md). Three parts. A user-delegated agent runs every night, pulls topics from hosted registries, and writes its outputs to a hosted environment. The hosted environment serves registry lists and the outputs of topic runs. The repository holds the agent instructions and the hosted environment's code, so anyone can run the agent or stand up their own environment. personalpaper.org is the default for both pulls and writes. Private topics are the next release. The PRD's section 8 is the canonical text; this page is its diagram.

3. How the agent writes to the hosted environment

Pulling from the registry is a public read. Writing outputs needs a credential, and a routine must never see it. The documented answer is a network secret on the routine's cloud environment: Anthropic's proxy attaches the token to requests leaving the session for the hosts you name, so the token never enters the session, the prompt, or the repository. Two alternatives are recorded beneath it.
